    Data minimization

    Calculations run in your browser. Your name and city are not sent to the AI advice service.

    Optional storage

    Analysis data is sent to the server-side storage endpoint only after you choose to save and provide consent. Clear local recent summaries at any time.

    Deployment configuration

    API keys and Google service account credentials belong in server environment variables, never in browser code.
